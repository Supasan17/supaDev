# supaDev

A personal practice repository for learning Git and GitHub workflows.

## What's here

- Branching, pull requests and merge commits
- Writing commit messages, including `Co-authored-by` trailers for pair work
- GitHub Discussions (Q&A)

## Workflow

1. Create a branch from `main`.
2. Commit with a clear message.
3. Open a pull request and merge it with a merge commit.
